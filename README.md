# Vasyuki Chess

An editorial landing page inspired by the fictional Vasyuki chess tournament.

![Preview of the landing page](docs/preview.png)

## Overview

An editorial landing page inspired by the fictional Vasyuki chess tournament. The layout adapts to desktop and mobile screens.

## Features

- Horizontal stage carousel and participant controls
- Native support dialog
- Locally hosted web fonts and responsive layouts

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```text
├── index.html
├── assets/css/style.css
├── assets/js/app.js
├── assets/img/
├── assets/fonts/
├── docs/preview.png
└── README.md
```

## Live Demo

https://dayiawan.github.io/vasyuki-chess/

## Running Locally

Open `index.html` directly in a browser or serve the folder with `python3 -m http.server 8000` and open `http://localhost:8000/`.

## Notes

- No build step or package installation is required.
